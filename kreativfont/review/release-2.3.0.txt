Changes
- Latest 10 commercial and latest 10 free font articles on separate horizontal shelves.
- Load 10 more at the end of each shelf, independent paging, preserved scroll,
  deduplication, explicit catalogue end, loading and retry states.
- Search the full public font catalogue using WordPress search (font categories
  3 and 23584), relevance ordering, 10 results per page and Load 10 more.
- Search results keep category badges, artwork, descriptions and local favorites.
- User-approved additions in this same 2.3.0: All / Commercial / Free search
  filters query the full server catalogue, reset pagination when changed, and
  persist the selected filter across activity recreation.
- Tapping artwork opens a private, full-screen viewer of the original website
  image where available. Pinch zoom, bounded panning, double-tap zoom/reset,
  Zoom in / Zoom out / Fit buttons, retry and zoom-state recreation are supported.
  Decode size is bounded to 2048 x 2048; existing cached/favorite images remain
  compatible. No synthetic specimens or font installation are introduced.
- Search is debounced; replaced queries and destroyed activities ignore late replies.
- Fixed short search batches caused by overlapping cached server pages. The
  worker keeps a per-query/filter queue and ID set, reads additional source pages
  to deliver 10 unique fonts (unless exhausted), and retains surplus for the next
  tap. Partial progress survives request failure/Retry; per-tap work is bounded
  to five source pages. Query/filter changes discard the old session. Article
  deduplication remains enabled, with no fake/repeated cards or weaker assertions.
- Favorites search remains local. No accounts, ads or analytics SDKs were added.
- Northlight-style centered footer below website/privacy links: "Version 2.3.0 ·
  Made by Kreativ". The displayed version comes from BuildConfig.VERSION_NAME;
  it is not hard-coded. The footer is present on Fonts, search and Favorites.
- Only "Made by Kreativ" is now a tappable indigo credit linking to the
  user-selected https://madebykreativ.com/apps in the preferred browser, with a
  48dp touch target. The version stays plain text. This exact trusted URL is
  allowed without broadening the catalogue's article/image URL validation.
- AndroidX Fragment constrained to 1.9.1, replacing the 1.3.6 transitive request
  from Glide 4.16.0, matching Northlight's dependency-constraint approach.
- 15 October UI refinement: the end-of-shelf card now matches the carousel height,
  has a tinted indigo outline and a centered call to action. A full-width,
  section-labelled Load more button below each carousel makes paging discoverable
  without swiping to the end. Both use the same state and minimum 56dp tap targets.
- Device regression coverage now checks end-card alignment, button bounds/tap size,
  full-width footer placement, and paging through both end-card and footer actions.
  These layout assertions passed on the real Samsung on 15 October.

Suggested replacement for the privacy appendix's "Data stored on your device"
paragraph:

Favorites, cached article information and preview images are stored in the app's
private storage on your device. Searching your saved favorites filters them locally.
The native app does not upload favorites or persist search phrases. You can remove
favorites individually. Clearing app storage or uninstalling removes local data.
Android cloud backup and device transfer are disabled for the app.

Suggested new paragraph under "Catalogue requests and hosting logs"
(DRAFT; NOT PUBLISHED):

Searching the website catalogue from the app sends your search phrase to
kreativfont.com in an HTTPS request so that the website can return matching font
articles. Search phrases are part of the requested URL and may therefore appear
in the hosting logs described below. An internet connection is required. Avoid
entering personal or sensitive information in font searches. This is separate
from the local search of saved favorites.

Also revise the final contact paragraph to distinguish inaccessible local favorites
