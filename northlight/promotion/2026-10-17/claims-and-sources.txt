Source photographs/screens: real sensor and GPS states on a Galaxy A55, captured from the separate release-UI preview package on October 15. No private gallery, account flow, purchase or simulated reading is shown. The GPS example is 94 m with reported uncertainty of plus/minus 84 m (68 percent confidence), visibly marked low accuracy. Never replace that uncertainty with a more attractive value.

Approved claims: magnetic north; free basic compass, speech, optional GPS altitude, lantern/red light/SOS; offline tools subject to hardware and voice/reception requirements; optional one-time paid Pro; no account/ads/analytics; on-device location/speech handling as described in the policy. Google Play purchases and ownership checks use internet access.

Avoid: accurate everywhere; true north; route navigation; offline maps; obstacle detection; safe-crossing or rescue claims; GPS tracking/history; barometric altitude; guaranteed night-vision preservation; no network traffic; guaranteed install growth; speech or Pro functionality demonstrated when only a static benefits page is pictured. SOS does not call anyone.

The website app page currently omits the live speech/altitude features and uses an older screenshot. website-copy-proposal.json and tutorial/PUBLISHING-NOTES.txt cover an unpublished correction. The website repository was not edited.
