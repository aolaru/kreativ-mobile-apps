SIGNING CHOICE TO RESOLVE BEFORE UPLOAD
- Prefer an APK signed with the same app-signing certificate as the installed
  Google Play edition if that production key is under the owner's control.
- A Play upload key may differ from Google's Play app-signing key. Using the
  upload key does not establish cross-store update compatibility.
- Samsung manages signing for AAB uploads. It can use an existing key supplied
  through its workflow or a Galaxy Store signing key. This decision is part of
  registration, not something this preparation silently selects.
- If Samsung and Play certificates differ, the same package cannot replace an
  installation from the other store. Decide whether a separate Samsung package
  is preferable before publication. A package change also needs privacy-policy
  coverage and a fresh build/test pass; this pack has not made that change.

The locally tested QA artifact uses .releasecheck and a debug certificate only
for device validation. It must never be used as the production store upload.
