# Privacy policy draft — development edition

This draft is not a published policy. Before launch, add the developer's legal identity, support contact, hosted URL, effective date and any applicable third-party SDK details.

BLOCKSHIFT, by Made by Kreativ, is an offline single-player puzzle. This development edition does not create accounts, use analytics, contact a server, or include advertising or billing SDKs. It does not request an internet permission.

Scores, statistics, settings, daily results and one saved board for each game mode are stored in private app storage on the device. The developer does not receive them. This build disables Android app backup. Resetting local progress in Settings removes those game records from the installation; Android's app-storage controls and uninstall can remove app data as well. Physical device and OS storage behavior should be verified before release.

The VIBRATE permission supports optional local haptic feedback. Haptics can be disabled in Settings. The game does not need camera, microphone, location, contacts or shared-storage access.

Purchases and advertising are unavailable in this edition. Before adding Google Play Billing, advertising, consent or analytics components, update this policy and Play disclosures to describe their actual data practices and user controls. No claim about the final commercial edition's collection practices is made by this draft.
