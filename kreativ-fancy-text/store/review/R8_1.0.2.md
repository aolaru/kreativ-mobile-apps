# R8 / AGP release update — 1.0.2 (5)

Prepared locally on 1 November 2026 in response to Google's R8 recommendation.
On **4 November 2026**, the exact signed release passed native Galaxy A55 tests,
was uploaded to production release 2 and was sent for review. Publishing overview
confirms **Changes in review**, with automated quick checks running. Rollout is
100% across all 178 targeted destinations; managed publishing is off. Approval,
public 1.0.2 availability and clearing of the historical Console recommendation
remain unverified. See `NATIVE_RELEASE_1.0.2.md` and
`play-1.0.2-submitted-2026-11-04.png`. Last verified live version is 1.0.1.

## Changes

- Android Gradle Plugin 8.13.0 → 9.0.1; Gradle 8.14.3 → 9.1.0.
- Replace `proguard-android.txt`, which includes `-dontoptimize`, with
  `proguard-android-optimize.txt`. Keep release minification and resource shrinking.
- Retain AGP 9's full-mode R8 and integrated resource-shrinking defaults.
- Keep Capacitor's runtime annotation interfaces/defaults, reflected plugin
  classes, exported methods and activity/permission callbacks.
- Retain Capacitor 8.5.3. Use the documented temporary `android.builtInKotlin=false`
  and `android.newDsl=false` compatibility settings for its external Kotlin
  plugin. These settings must be removed after plugin migration before AGP 10;
  they do not disable R8 optimisation.
- Use the aggregate Gradle unit-test task because AGP 9 only creates tests for
  the tested build type (debug by default). JVM tests do not exercise shrunk DEX.
- Deliver the effective merged R8 configuration alongside the mapping file and
  record AGP from the actual AAB metadata. Release verification checks those
  outputs plus runtime plugin annotations/defaults in the packaged DEX.
- Advance app/package metadata to 1.0.2, version code 5; preserve application ID
  and upload key. No product feature or permission changes.

## Validation

Five model/history tests and 18 desktop/mobile Chromium tests passed against
the 1.0.2 web build, including offline use, persistence, PNG decoding,
Undo/Redo/deletion recovery and accessibility checks. Refreshed local store
graphics are versioned 1.0.2; this does not change saved Play listing drafts.

The signed APK/AAB build and release lint passed. The Gradle JVM test task also
passed; its single template arithmetic test provides no R8 runtime coverage.
All **18 release checks passed**, including signatures against the existing
upload certificate, exact bundled assets, permissions/backup rules, AGP 9.0.1
in the actual AAB metadata, effective optimisation rules and preserved runtime
annotations/defaults for the four bundled plugins plus the custom export plugin.
No global `-dontoptimize`, `-dontshrink` or `-dontobfuscate` remains in the merged
R8 configuration.

Results are recorded in `artifacts/play/verification.json`. Build log:
`artifacts/release-r8-1.0.2-build.log`; browser/model log:
`artifacts/release-r8-1.0.2-tests.log`.

verification. Its log is `artifacts/release-r8-1.0.2-incremental-build.log`;
verification output is `artifacts/release-r8-1.0.2-verification.log`.
