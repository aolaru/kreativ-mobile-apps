## Passed checks

- Debug/release JVM suites: 16 tests each, no failures/errors/skips.
- Release lint: zero errors / 39 warnings. Existing upload-key signature verifies.
- DEX: 1,430,972 bytes, 1,356 defined classes, 1,314 renamed (96.90% local coverage).
  APK/AAB DEX identical; deobfuscation mapping embedded. This is not Play's metric.
- Samsung SM-A556B / Android 16: 24 QA tests and four ordered non-debuggable,
  R8/resource-shrunk black-box workflows. Separate `.v120.qa` and `.r8test`
  packages preserve production and the owner's old QA installation.
- Free crop, export, draft/Activity recovery and Recent PDFs; protected export,
  password-free saved presets, compact/grayscale Letter output, merge, extraction,
  13-page export, logo import/preset reuse and existing-PDF editing.
- Editor regressions preserve vector/text content, source bytes, crop/media boxes
  and inherited resources. Independent duplicates get separate annotations.
  Retained local destinations are remapped; removed destinations are dropped.
  Encrypted and fillable inputs are rejected without changing them.
- Fixed a real link-removal bug: PDFBox's COSArrayList iterator removal leaves its
  backing PDF array unchanged. Filter a plain list and write back the annotations.
- Independent pypdf checks on all eight R8 outputs: page counts, A4/Letter sizes,
  numbering, logo alpha/opacity, edited page rotation, AES-256 and rejection of
  missing/wrong passwords. QA fixtures also verify text order, annotations and
  the unmodified fillable source's field tree.
- Poppler reviewed all 38 R8 pages and 19 QA pages. At one `-scale-to 700` size,
  this desktop renderer omitted some masked images. Normal 72/100 dpi and 1200px
  renders show them correctly; Apple Quartz independently renders the logo page.
  Android PdfRenderer additionally checks dark-content pixel counts on every
  unencrypted R8 page at 300×420, so a logo/number alone cannot pass as content.
- Phone UI reviewed with actual device captures, including editor controls and
  bottom system-bar clearance. The short-document list now uses only the space
  it needs; editor option labels stay concise.

## Release limits

The isolated APK uses the same release optimisation configuration, a separate
package ID and debug signing key. It is not a test of a real Play purchase.
The owner's real-payment and Android 8/9 test waivers remain in force; neither
is claimed as passed. Signed PDFs are deliberately rejected by the editor.
No production installation or user documents were modified. Play submission and
publication require the final reviewed draft; this report does not claim either.
